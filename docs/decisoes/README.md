# Decisões

Uma nota por decisão que muda o jeito de trabalhar no projeto. Nada é reescrito: quando uma decisão
muda, entra uma nota nova que diz qual ela substitui.

Nome do arquivo: `NNNN-assunto-curto.md` (número seguido). Cada nota tem quatro partes, em poucas linhas:

- **Situação:** proposta, aceita ou substituída (por qual nota).
- **Contexto:** o problema e o que pesava na hora.
- **Decisão:** o que foi escolhido.
- **Consequências:** o que fica mais fácil, o que fica mais difícil e o que precisa ser feito.
